# Yoga Lizza

- Работай в текущем чате. Используй контекст и читай только файлы, нужные для задачи.
- Делай точечные правки. Сохраняй архитектуру, дизайн, адаптивность и рабочие функции.
- Избегай повторов и лишних проверок. Выполняй необходимые проверки качества, доступности и производительности.
- Решай понятные задачи самостоятельно. Уточняй только при существенном риске ошибки.
- В итогах кратко сообщай, что изменилось и как проверено. Обновляй этот файл только при существенных изменениях.
- Главная страница размещена на Cloudflare Pages из main. Личный кабинет находится в ветке codex/yoga-club, а подписки и закрытые файлы обслуживает Supabase. Проверяй подписку на сервере перед выдачей доступа к видео. Храни видео в закрытом хранилище и открывай их в плеере кабинета.
