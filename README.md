# Yoga Lizza

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. Контент и структура собраны по приложенным ТЗ и документу с текстами.

## Как открыть

Откройте `index.html` в браузере или запустите локальный статический сервер из этой папки:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Перед публикацией

Заменить заметные поля `[УТОЧНИТЬ]` и фото-заглушки на подтверждённые сведения и реальные изображения. Добавить политику конфиденциальности, ссылки соцсетей и контакт. Подключить безопасный серверный endpoint для формы и Telegram Bot API; секреты хранить только в переменных окружения. Сейчас форма валидирует поля, но сообщает, что заявка не отправлена.
