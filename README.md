# Yoga Lizza

Адаптивный одностраничный сайт на HTML, CSS и JavaScript. Контент и структура собраны по приложенным ТЗ и документу с текстами.

## Как открыть

Откройте `index.html` в браузере или запустите локальный статический сервер из этой папки:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
