# Запуск личного кабинета Yoga Lizza

1. В тестовом проекте Supabase включите вход по почте и паролю, выключите самостоятельную регистрацию и настройте SMTP для приглашений и восстановления. Добавьте точный адрес страницы `/club.html` в список разрешённых URL. Используйте стандартный поток Supabase с передачей сессии во фрагменте URL.
2. Выполните `club.sql` в SQL Editor. Загрузите пробный MP4 в закрытый бакет `club-videos`.
3. В Cloudflare Pages задайте для Preview переменные `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `CLUB_VIDEO_PATH` (путь внутри бакета) и секрет `SUPABASE_SECRET_KEY`. Повторно запустите сборку.
4. После подтверждения оплаты отправьте приглашение из Authentication → Users. Скопируйте ID пользователя. В Table Editor → club_memberships добавьте строку с этим ID и датой окончания доступа. Для продления обновите поле expires_at у существующей строки.
5. Проверьте вход по приглашению, сброс пароля, выход, активный и истёкший доступ. Проверьте видео на телефоне и компьютере. При публикации повторите настройки для production.

Временная ссылка действует до часа и истекает не позже окончания подписки. Повторное открытие видео запрашивает новую ссылку.

## Вход через Google

Создайте OAuth-клиент типа Web application в Google Cloud. Добавьте callback Supabase в Authorized redirect URIs и внесите Client ID и Client Secret в Supabase → Authentication → Providers → Google. Укажите точный адрес кабинета на предпросмотре в списке Redirect URLs Supabase. Включите `CLUB_GOOGLE_ENABLED=true` в окружении предпросмотра. Для теста используйте Google-аккаунт с тем же адресом, который использован при приглашении, и проверьте, что он попадает в существующую учётную запись со своим сроком доступа.

## Плейлист для предпросмотра

В настройках Preview задайте `CLUB_ENABLE_YOUTUBE_PREVIEW=true` и `CLUB_PREVIEW_YOUTUBE_PLAYLIST_ID` со значением параметра `list` выбранного плейлиста. Храните идентификатор в Cloudflare. После проверки подписки кабинет покажет ссылку для открытия YouTube. Плейлист с доступом по ссылке можно переслать, поэтому эта настройка предназначена для проверки. Для платного доступа используйте закрытый MP4 из бакета и оставьте переменную `CLUB_ENABLE_YOUTUBE_PREVIEW` выключенной в Production.
